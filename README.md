# IS Codes Repository

This repository contains source codes for Information Security (IS) practicals. Each practical demonstrates key cryptographic concepts implemented in various programming languages such as C++, Python, Java, HTML, and JavaScript.

## Practicals Overview

### 🔐 Practical 1: Plain Text to Cipher Text using Bitwise Logic (AND, OR, XOR)
- **Filename**: `pr1 - AND, OR, XOR.cpp`
- **Language**: C++
- **Description**: Converts a plain text string into cipher text using bitwise logic operations: AND, OR, and XOR. Useful for understanding low-level bitwise encryption techniques.

### 🧱 Practical 2: Rail Fence Cipher
- **Filename**: `pr2 - Rail Fence Cipher.py`
- **Language**: Python
- **Description**: Implements the Rail Fence Cipher encryption and decryption technique. A classical transposition cipher that rearranges the characters of the plaintext.

### 🔑 Practical 3: DES (Data Encryption Standard)
- **Filename**: `pr3 - DES.java`
- **Language**: Java
- **Description**: Java implementation of the DES encryption algorithm, a widely used symmetric-key block cipher.

### 🔐 Practical 4: RSA Algorithm
- **Filename**: `pr4 - RSA.py`
- **Language**: Python
- **Description**: Implements RSA public-key cryptosystem including key generation, encryption, and decryption processes.

### 🤝 Practical 5: Diffie-Hellman Key Exchange
- **Folder**: `Practical 5/`
- **Languages**: HTML, JavaScript
- **Description**: A web-based simulation of the Diffie-Hellman Key Exchange protocol. Allows two users to securely generate a shared secret over an insecure channel using modular arithmetic and exponentiation.

## Getting Started

To run the codes:
- Make sure the required language compilers/interpreters are installed.
- Navigate to the respective files/folders.
- For **Practical 5**, open the `index.html` file in a modern web browser.
